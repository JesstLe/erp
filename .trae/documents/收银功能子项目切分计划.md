# 收银功能子项目切分计划

## 一、项目概述

将当前 jshERP 项目中的收银功能切分出来，创建一个独立的精简子项目。子项目文件夹放置在当前项目的上一层目录中。

### 目标
- 提取收银核心功能，去除不必要的进销存、采购、销售等模块
- 保留收银所需的基础依赖（用户、门店、会员、商品等）
- 精简数据库表结构
- 创建可独立运行的前后端项目

---

## 二、收银功能范围界定

### 2.1 核心收银功能（保留）

| 功能模块 | 说明 |
|---------|------|
| 前台收银 | 座席管理、开台/清台、服务下单、产品销售、结算支付 |
| 服务项目管理 | 服务项目的增删改查 |
| 会员管理 | 会员信息维护、储值、余额查询 |
| 门店管理 | 多门店支持、门店权限 |
| 收银交班 | 开班、交班、备用金管理 |
| 签单挂账 | 挂账、清账 |
| 发票申请 | 发票信息采集、开票管理 |
| 顾客看板 | 顾客消费统计 |
| 顾客报表 | 消费报表 |

### 2.2 需要精简的模块（移除）

| 模块 | 说明 |
|------|------|
| 采购管理 | 采购订单、采购入库、采购退货 |
| 销售管理 | 销售订单、销售出库、销售退货 |
| 零售管理 | 零售出库、零售退货（收银已独立实现） |
| 仓库管理 | 调拨、组装、拆卸、其他出入库 |
| 财务管理 | 收入单、支出单、收款单、付款单、转账单（收银结算已独立） |
| 报表查询 | 进销存统计、采购统计、销售统计等（保留顾客相关报表） |
| 序列号管理 | 序列号跟踪 |
| 生产管理 | 组装单、拆卸单 |
| 请购单 | 采购申请 |

### 2.3 基础依赖模块（保留但精简）

| 模块 | 保留内容 |
|------|----------|
| 用户管理 | 用户、角色、权限、登录 |
| 商品管理 | 商品信息、商品类别、多单位、多属性（用于产品销售） |
| 门店管理 | 门店信息、用户门店权限 |
| 会员管理 | 会员信息（复用 Supplier 表，type=会员） |
| 经手人管理 | 技师信息（Person 表，type=技师） |
| 账户管理 | 结算账户（用于支付方式） |
| 系统配置 | 基础系统参数 |
| 租户管理 | 多租户支持 |
