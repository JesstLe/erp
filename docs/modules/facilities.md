# 门店设施与接待模块

## 目标

将“资源怎么配置”和“资源当前怎么使用”分离：门店设施配置负责服务区、服务位和说明信息；设施接待负责占用、服务器计时、暂停、换位、结束和清洁。

## 配置层级

`租户 → 门店 → 服务区 → 服务位`

- 服务区名称和服务位名称是看板定位所需的结构字段，必须填写。
- 服务名称、内部设施名称、参考单价、设施类型、清洁分钟和预约标记均可选。
- 服务位编号由系统按门店自动升序生成，创建后不可修改，停用后不复用。
- 参考单价是信息提示，不参与价格版本、消费单、支付或报表金额计算。

## 权限

- `OWNER`：读取租户内全部门店的店长、服务区和服务位配置，并进行跨店新增、编辑、维护或停用。
- `STORE_MANAGER`：只读取和修改账号授权门店的服务区与服务位。
- 前台：可按权限操作日常接待，不可修改配置。
- 收银员及其他角色：不获得设施配置写权限。

所有服务端查询和写入均按租户校验；店长额外校验门店授权。前端隐藏按钮不作为授权边界。

## 历史和状态

- 不提供物理删除；不再使用的服务位通过停用保留历史关联。
- 正在使用的服务位不能切换为维护或停用。
- 编辑配置不改写已有接待、计时、消费单或支付事实。
- 设施计时与收费继续严格分离。
