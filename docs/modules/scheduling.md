# 预约与排班模块

## 核心对象

- 预约：门店、顾客、服务项目、可选员工、可选设施、计划区间、状态和接待关联。
- 员工班次：门店、员工、计划区间、状态和取消原因。

## 状态机

- 预约：`Scheduled → Arrived | Cancelled | NoShow`，终态不可覆盖。
- 班次：`Scheduled → Cancelled`，取消替代物理删除。

## 核心规则

- 同一员工或设施的待到店预约不得重叠；同一员工的有效班次不得重叠。
- 到店在串行化事务中创建接待，指定设施时再次校验实际占用和清洁状态。
- 预约计时不参与计价，服务项目也不会自动生成收费。
- 写操作校验角色、租户、门店、乐观并发版本；创建和终态转换使用幂等命令。
- 顾客手机号保持加密存储、摘要查询和视觉脱敏，审计不记录明文。

详细操作与验收见 [预约与员工排班](../user-manual/18-appointments-and-employee-scheduling.md)。
