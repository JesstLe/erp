# 文档与截图新鲜度审计（2026-08-22）

## 结论

本轮按当前工作区功能基线 `ca480e84` 复核 README、模块化用户手册、开发进度、Changelog 和全部手册图片引用。README 的业务边界、菜单、自动编码、人工收款、交班自动关班和旧系统迁移说明已覆盖最新实现；模块化手册是当前操作依据。早期合并版 `ERP-V1-user-manual.md` 只保留历史语境，不再承担当前使用指南职责。

## 已移除截图的判定规则

满足任一条件即从当前文档中删除：

1. 图片文件名描述的页面或状态与实际画面不一致；
2. 多个业务状态文件的内容哈希完全相同，无法证明对应状态；
3. 截图仍展示手工输入业务编码，而当前实现已改为后端自动生成不可变编码；
4. 截图仍展示“库存单据过账”等已被当前“调整库存/调整数量”替代的文案；
5. 收银截图未体现“开班并结算”、人工外部收款待核对和无异常交班自动关班等最新规则；
6. 图片只来自早期合并手册，且无法从当前页面稳定复现。
