# 产品目录与版本化标准价

适用版本：V1 产品目录首个闭环

更新日期：2026-08-18

## 1. 第一版边界

本模块维护产品编码、名称、计量单位、库存属性预留标记和版本化标准售价。最高权限账号负责建档和发布价格。

第一版不包含采购入库、零售销售单、库存余额、调拨、盘点、批次、效期和成本。页面明确提示：勾选“后续需要管理库存”只保存主数据属性，不代表库存已经产生。

## 2. 新建产品

![新建产品表单](assets/33-product-create-form.png)

| 字段 | 是否必填 | 规则 |
|---|---|---|
| 产品编码 | 必填 | 最长 40 字，保存时转大写；同一租户内唯一 |
| 产品名称 | 必填 | 最长 120 字；不写死行业名称 |
| 计量单位 | 必填 | 最长 20 字，例如件、盒、套 |
| 后续需要管理库存 | 选填 | 只作为后续库存模块预留属性，当前不生成库存流水 |

只有 `OWNER` 可以保存产品。重复编码由数据库唯一约束和服务端检查共同阻止；保存失败不会生成半条产品记录。

## 3. 产品目录

![产品目录](assets/34-product-catalog.png)

列表分别展示编码、名称、单位、库存属性和状态。新产品默认启用。已被价格版本或未来业务引用的产品不允许物理删除；停用和编辑动作尚未在第一版页面开放。

## 4. 在价格版本中定价

![产品标准价表单](assets/35-product-versioned-price-form.png)

价格版本同时包含服务项目价格和产品价格。每个已有目录条目都需要填写非负标准价，金额按整数分存储。产品价格使用独立的产品价格明细表，不给消费单表增加“产品金额”固定列。

先“保存草稿”，核对后由 `OWNER` 点击“发布”。已发布版本只读；调整产品价格必须创建新版本，历史版本和未来单据价格快照不会被覆盖。

![已发布的产品标准价](assets/36-product-versioned-price.png)

## 5. 与收银和库存的关系

- 服务录单仍只选择服务项目；产品销售尚未开放，不能通过备注或服务项目伪装成产品出库。
- 服务订单按门店日期选择已生效价格版本；同日多版本按最后发布时间选择。
- 产品价格已具备历史版本基础，但在产品销售模块落地前不会产生应收、支付或库存变化。
- 后续库存模块应基于不可变出入库流水形成余额，不能直接修改产品目录字段来调库存。
