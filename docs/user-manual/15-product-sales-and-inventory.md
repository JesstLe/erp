# 商品销售与门店库存

版本：V2 开发版

日期：2026-08-22

## 1. 功能边界

本模块实现门店级、整数数量的商品库存闭环：库存单据入库/调整、消费单商品预占、结算出库、作废释放和销售退货入库。批次、效期、单位成本、盘点单、跨店调拨和采购入库由“采购与供应链”页面处理；序列号、多单位换算、采购订单、采购退货和供应商应付付款仍不在当前范围。

设施占用和计时仍只记录现场信息，不影响商品库存，也不自动决定收费金额。

## 2. 商品库存页


页面同时显示：

- 账面库存：已经正式入库、扣除正式出库后的实物账面数量。
- 销售预占：消费单已经确认、但尚未结算的商品数量。
- 可用库存：账面库存减销售预占；确认消费单时按此数量校验。
- 库存流水：期初、收货、销售出库、销售退货、盘盈和盘亏的不可变事实。

有库存写入权限的账号可点击右上角“调整库存”，也可在某个商品行点击“调整数量”。系统不会提供直接覆盖余额的输入框：用户必须选择期初、收货、盘盈或盘亏，填写变动数量和原因后确认过账。店长可按授权查看本门店余额、单据和流水。已过账记录不能编辑或删除，录错时必须新增反向调整单并填写原因。

## 3. 库存单据字段

| 字段 | 必填 | 规则 |
|---|---|---|
| 调整类型 | 是 | 期初、收货、盘盈、盘亏四选一；前两项和盘盈增加库存，盘亏减少库存 |
| 产品 | 是 | 只能选择已启用且勾选“跟踪库存”的产品；同单不得重复 |
| 变动数量 | 是 | 1–1,000,000,000 的整数，不填写正负号，由调整类型决定方向 |
| 变动原因 | 是 | 1–500 字；写入审计记录 |

期初库存只允许在该产品尚无库存流水时录入。盘亏数量不能超过当前可用库存，不能挪用已经被消费单预占的数量。

## 4. 消费单商品流程

1. 最高权限账号先建立产品，并在已发布价格版本中配置标准售价。
2. 跟踪库存的产品先通过期初、收货或盘盈单建立库存。
3. 店长录消费单时可仅选服务、仅选商品或混合选择；商品数量不填写服务时长，服务行也不要求关联商品。
4. 保存草稿不改变库存。
5. 确认消费单时预占商品；库存不足时整单确认失败，不产生部分预占。
6. 完成现金、会员或可信渠道收款时，消费单结算与销售出库在同一数据库事务中完成。
7. 草稿或待支付消费单作废时释放预占，不生成销售出库流水。

不跟踪库存的产品仍可销售和保留价格快照，但不会形成库存余额或流水。

## 5. 商品退货与资金退款

只有最高权限账号可以对已结算消费单登记商品退货。退货数量累计不得超过原销售数量；跟踪库存的产品会生成“销售退货入库”流水。

商品退货和资金退款是两个独立动作：

- 商品退货确认实物已经回到门店。
- 资金退款必须另行从原支付分摊发起，经过既有退款审批和原路退款规则。
- 系统不会因为商品回库就自动退款，也不会因为资金退款就假定实物已退回。

## 6. 审计和不可变约束

库存单据、销售出库和销售退货均记录来源单据、来源明细、幂等请求号、操作人或系统来源、发生时间以及变动前后账面数量。数据库禁止更新或删除库存流水；并发确认、结算、作废和退货使用串行化事务、聚合版本号与唯一约束防止超卖和重复出入库。
