# 产品图片与顾客服务档案

版本：V2 开发版

日期：2026-08-18

## 1. 产品可选图片


产品图片用于帮助门店员工快速辨认商品，不参与定价、库存、结算或报表计算。产品创建后，最高权限账号可以在产品列表执行“上传图片”或“更换图片”；不上传图片不影响产品发布和销售。已上传的封面也会出现在收银端的商品选择列表中，未上传时显示统一占位图。

| 字段 | 必填性 | 规则 |
|---|---|---|
| 产品图片 | 选填 | JPEG、PNG、WebP；单张不超过5MB；每个产品当前展示一张封面图 |

更换图片只更新产品当前封面引用，历史价格、订单和库存流水保持不变。旧文件元数据继续保留，后续通过独立保留期策略清理，不能在更换图片时顺带删除业务记录。

## 2. 顾客服务档案


服务档案位于“顾客与会员”详情中，用于记录某次到店服务的过程、结果与图片。它类似服务过程存档，但不是消费单、支付单或专业医疗病历：消费金额以原消费单为唯一来源，不在服务档案中重复输入。

| 字段 | 必填性 | 规则 |
|---|---|---|
| 服务时间 | 系统必填 | 打开表单时自动填入当前时间，可改为过去时间，不能晚于当前时间 |
| 关联消费单 | 选填 | 只能选择同一门店、同一顾客的消费单；关联后只展示单号，不复制金额 |
| 服务记录分类 | 选填 | 可在档案页面直接添加、编辑、停用或删除未使用分类 |
| 护理老师 | 选填 | 从当前门店的在职员工中选择，档案同时保存人员编号和姓名快照 |
| 回访提醒时间 | 选填 | 到期前24小时起在右上角铃铛显示“顾客护理提醒”；鼠标悬停即可查看，点击后直达该顾客的服务档案；顾客产生后续服务记录后旧提醒自动完成 |
| 本次情况/需求 | 选填 | 最多2000字 |
| 服务过程与内容 | 选填 | 最多4000字 |
| 结果与后续建议 | 选填 | 最多2000字 |
| 服务图片 | 选填 | 最多6张；单张不超过5MB；仅JPEG、PNG、WebP |

除自动生成的档案编号、顾客、门店、服务时间、建档人和建档时间外，文字、消费单关联和图片都允许留空。因此可以只登记一次服务时间，也可以形成完整图文档案。

## 3. 权限与隐私

- 产品图片：当前只有 `OWNER` 可以上传或更换，已登录业务人员可以在产品目录读取当前封面。
- 服务档案：当前只有 `OWNER` 和 `STORE_MANAGER` 可以创建、查看文字和读取图片；前台与普通收银员不可见。
- 服务图片不是公开静态文件。每次读取都重新校验登录状态、租户、门店、顾客和角色，复制图片地址不能绕过权限。
- 服务档案创建后只读；需要补充或纠错时追加新快照，不覆盖原始记录。员工无需填写“更正原因”，系统自动记录为日常补充更新，并保留操作人和时间。数据库禁止更新或删除档案、附件关系和文件元数据。
- 文件使用随机存储键并加密落盘，数据库只保存用途、原始文件名、类型、大小和 SHA-256 完整性摘要，不保存图片二进制和服务器绝对路径。

## 4. 当前边界

- 当前不提供图片裁剪、压缩、标注、分类、批量下载和外部对象存储。
- 当前不提供服务档案原地编辑或删除；已经提供追加补充/更正关系，仍不得覆盖历史。
- 如果业务属于医疗、诊疗或其他受监管行业，必须在正式上线前另行完成适用法规、数据保存期限、顾客授权和专业病历要求评审；本模块不能自动视为合规医疗系统。
