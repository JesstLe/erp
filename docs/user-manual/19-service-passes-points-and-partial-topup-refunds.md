# 次卡、积分与储值部分退款

适用版本：V2 会员扩展闭环
更新日期：2026-08-18

## 1. 储值部分退款

储值本金和赠送奖励始终分账。退款只能从原储值支付单发起，累计退款不得超过原储值本金；已申请但尚未完成的金额也会占用可退额度。

退款按累计比例向上取整收回赠送奖励。例如本金500元、赠送100元，第一次退本金200元时收回40元赠送奖励；剩余本金300元、赠送60元。后续再次退款时按累计应收回额减去已收回额计算，避免分多次退款产生舍入套利。

只有账户仍有足够本金和本次应收回赠送奖励时才能批准。已被消费的余额不能通过退款变成负数；系统返回明确阻断，不直接改余额。申请由店长或最高权限提出，只有 `OWNER` 批准；原储值单、支付分摊和既有流水均保留。

## 2. 次卡

顾客详情的“次卡与积分”区域支持发放、核销、撤销核销和到期处理。

- 发放时必须选择会员卡、服务项目、次卡名称、生效日、购买/赠送次数和原因；到期日可选。
- 购买次数与赠送次数分开保存，核销固定先扣购买次数，再扣赠送次数。
- 核销可以选填消费单编号；填写后服务端要求消费单属于同一顾客并包含对应服务项目。
- `OWNER` 可以对尚未撤销的核销流水执行撤销；系统新增反向流水，不删除原核销。
- 到期日当天仍可使用；门店当地日期超过到期日后才能执行过期处理。
- 设施占用、计时和结束服务都不会自动核销次卡。

## 3. 积分

积分账户继续使用整数单位。`OWNER` 和门店店长可以增加或扣减积分，必须填写原因；增加积分时到期日可选。

扣减按“最早到期批次优先、长期批次最后”的顺序分摊。每一笔扣减同时保存账户不可变流水与所使用的积分批次。只有 `OWNER` 可以撤销人工扣减；撤销把积分恢复到原批次，若原批次已过期则拒绝恢复，避免过期积分重新生效。

到期积分不会因为打开页面而隐式改变。负责人点击“处理到期积分”后，服务端按门店日期把已过期批次归零并新增过期扣减流水；没有到期批次时返回明确提示。

## 4. 权限、并发与审计

- 查看次卡与积分余额：`OWNER`、门店店长、收银员；仍受授权门店限制。前台只能通过顾客普通详情查看不含余额的会员卡基础信息。
- 发放次卡、积分增减和过期处理：`OWNER`、门店店长。
- 次卡核销：`OWNER`、门店店长、收银员。
- 撤销次卡核销或积分扣减：仅 `OWNER`。
- 所有写操作使用幂等请求号；次卡修改同时校验版本号。
- 次卡和积分流水由数据库触发器禁止更新和删除；余额或余次只是受控投影。
- 操作者、门店、动作、原因、请求号、前后状态和时间进入审计，不记录手机号明文。

## 5. 当前边界

本版本实现门店内次卡权益发放、核销、撤销和过期，以及积分手工增减、撤销和过期。次卡商品定价、售卡收款、复杂退卡作价、积分自动按消费金额发放、兑换礼品和跨店权益清算仍属于后续独立交易链，不能以手工发放冒充已收款售卡。
