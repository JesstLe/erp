# 服务项目与价格版本

适用版本：V2 开发版

## 1. 业务原则

服务项目只描述“提供什么服务”和标准时长；设施计时只记录占用，不自动形成收费。最终标准价由系统最高权限账号通过价格版本建立并发布。已发布版本不在原记录上直接修改；如需调整，可复制为新草稿。产品目录和产品标准价见[产品目录与版本化标准价](10-product-catalog-and-pricing.md)。

## 2. 新建服务项目


进入“服务项目”，点击“新建项目”。

项目列表支持按编码或名称实时包含词匹配。输入停顿约 300 毫秒后自动刷新；启用/停用筛选选择后立即生效，清空关键词或点击重置恢复默认列表。

| 字段 | 是否必填 | 规则 | 业务含义 |
|---|---|---|---|
| 项目编码 | 系统生成 | 品牌内按 `SV000001` 递增；创建后不可修改、删除后不复用 | 稳定业务标识，不需要也不允许手工输入 |
| 项目名称 | 必填 | 最长 120 字符 | 门店自己定义，不写死行业名称 |
| 标准时长（分钟） | 必填 | 0–1440 的整数，默认 60 | 服务记录与排班参考，不自动计价 |
| 员工提成方式 | 必填 | 不计提、按成交金额比例或按每次服务固定金额 | 由负责人维护，录单人员不能临时改提成规则 |
| 提成比例/固定金额 | 条件必填 | 选择对应提成方式后必填；提成不能超过该服务明细成交金额 | 结算时按实际服务员工生成提成快照 |

点击“保存”才会写入；点击“取消”或关闭弹窗不会保存。新项目默认启用。负责人可以编辑名称、标准时长、提成规则和状态，也可以停用或恢复项目。只有从未进入价格、接待或订单的误建项目才能物理删除；已有业务记录的项目应停用，以保留历史账目。

## 3. 建立价格版本


进入“价格版本”，点击“新建价格版本”。服务与产品都不存在时按钮才会禁用；只存在其中一种目录时，仍可为该类型建立价格版本。

| 字段 | 是否必填 | 规则 | 业务含义 |
|---|---|---|---|
| 版本名称 | 必填 | 使用可识别的业务名称 | 例如某季标准价；用于历史查询 |
| 生效日期 | 必填 | 日期 | 版本计划开始适用的日期 |
| 本次调整的服务项目 | 选填 | 勾选后价格必填，不小于 0且精确到分 | 可只调整服务；未勾选的已有价格自动继承 |
| 本次调整的产品 | 选填 | 勾选后价格必填，不小于 0且精确到分 | 可只调整产品；不要求同时选择服务 |

服务和产品两类至少勾选一条。未勾选但已有生效价格的条目会继承到新版本快照；从未定价的条目不会自动变成零价，并保持暂不可销售。

首次点击“保存草稿”只建立草稿，不会立即成为正式价格。草稿可继续编辑，取消勾选的条目会从草稿中移除；由 `OWNER` 点击“发布”后才参与新订单定价。发布后本版本只读，后续改价可点击“复制”生成内容相同的新草稿。

列表支持输入版本名称后自动查询，并可按状态和生效日期筛选。点击“查看”可核对服务、产品和标准价明细。

`OWNER` 可以停用已发布版本，也可以删除草稿、已发布或已停用版本。删除必须填写原因并二次确认；删除后该价格版本不再展示，已有消费单仍保留订单行中的项目名称、标准价、成交价和金额，但不再显示被删除的价格版本标识。

## 4. 权限和可追溯性

- 服务项目和价格版本列表：已登录账号可查看。
- 新建服务项目、新建价格版本、发布价格版本：当前只允许 `OWNER`。
- 价格版本删除或后续调整都不会重算既有消费单的成交明细。
- 价格金额以整数分保存，避免浮点数舍入造成账务误差。

## 5. 当前边界

- 当前支持服务项目新建、实时查询、编辑、停用、恢复、受限删除和提成规则配置；价格版本支持自动查询、状态/日期筛选、详情、新建、草稿编辑、发布、复制、停用及任意状态删除。
- 已发布价格版本保持只读；如需改价，应复制或新建草稿。更细的分级价格审批仍需后续扩展。
- 当前页面中的本地示例项目和价格仅用于开发验收，不代表真实门店经营数据。
