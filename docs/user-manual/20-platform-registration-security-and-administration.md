# 商户注册、平台管理与登录安全日志

适用版本：V2 开发版
更新日期：2026-08-20

本模块服务于 ERP 运营方，不属于任何一个商户。平台管理员与商户 `OWNER` 使用不同账号体系、不同登录入口和不同会话 Cookie。

## 1. 商户提交注册申请

1. 打开 `/register`。
2. 填写商户名称、首店名称、联系人、手机号和期望负责人账号；邮箱和说明可不填。
3. 阅读并勾选服务及隐私条款后提交。
4. 页面返回申请编号和“待审核”状态。此时不会自动创建商户、门店或登录账号。

相同手机号或负责人账号已有待审核申请时，系统拒绝重复提交。手机号加密保存，平台列表只显示脱敏值。

## 2. 初始化并登录平台管理员

Linux 空库首次发布后，由服务器管理员执行：

```bash
sudo /usr/local/sbin/erp-platform-bootstrap
```

一次性账号与初始密码只写入 root 可读的 `/root/erp-platform-initial-credentials.txt`。通过 `/platform/login` 登录后必须立即修改初始密码，平台账号不能在商户员工页面中创建。

## 3. 审核注册申请

1. 登录 `/platform`，进入“注册审核”。
2. 按状态或关键词定位申请。
3. 批准时填写负责人初始密码和审批原因；品牌编码及首店编码不允许手工输入。
4. 批准成功后，系统自动生成品牌编码和首店编码 `S001`，并在同一事务中创建商户、首店、标准角色、负责人账号、员工档案和默认配置。
5. 初始密码保存后不回显，应通过约定的安全线下渠道交付负责人；负责人首次登录商户 ERP 时必须改密。

申请批准或驳回后不能再次处理。任何一步失败都不会留下半成品商户。

品牌编码格式为 `B + 日期 + 四位流水号`，例如 `B202608200001`。编码一经分配永久不可修改；编号允许因事务失败或运营原因出现跳号，不会回收复用。

## 4. 查看和启停商户

“全部商户”显示编码、名称、状态、门店数、员工数、登录账号数和创建时间，支持名称/编码查询及状态筛选。

- 停用和恢复都必须填写原因。
- 停用后，商户员工不能新登录；已有会话下一次访问受保护接口时失效。
- 停用不删除订单、会员资金、档案和审计历史。
- 平台没有物理删除商户按钮，也不能直接进入商户修改业务单据。

## 5. 查询登录安全日志

“登录日志”是只读页面，可按商户/平台范围、结果、账号和日期查询。事件覆盖登录成功、登录失败、账号锁定、退出、本人改密和管理员重置密码。

日志展示脱敏账号、商户、来源 IP、设备摘要、结果码、发生时间和追踪号；不保存或展示密码、Cookie、防跨站令牌、完整请求体及支付密钥。数据库禁止更新或删除安全事件和平台审计事件。

## 6. 权限边界

- 商户 `OWNER` 只能管理自己商户，不能访问 `/api/v1/platform/*`。
- 平台会话不能调用商户业务接口。
- 平台默认只能查看商户运营元数据，不能查看顾客隐私、会员资金明细或支付密钥。
- 模拟登录商户、跨租户业务查看、物理删除商户和平台多因素认证不在当前版本内。
