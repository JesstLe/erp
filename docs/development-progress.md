- API 编译：成功，0 警告、0 错误。
- 领域单元测试：本轮收银与支付过滤集 13/13 通过；累计测试总数将在最终全量测试时统一报告。
- 前端安全请求测试：2/2 通过。
- 前端静态检查：通过，0 警告。
- 前端生产构建：通过；当前入口包约 1.28 MB（gzip 约 405 KB），代码分包留到页面规模增长后处理。
- 依赖审计：npm 与 NuGet 当前均未发现已知漏洞。
- 数据库迁移：五个前向迁移均从空库在 PostgreSQL 18.3 临时容器执行成功，共 34 张表；18.4 目标镜像仍需复验。
- API 会话：登录 200、退出 204、退出后当前用户接口 401。
- 浏览器：登录、退出、服务项目列表、价格版本列表和设施完整状态流在 1280×720 视口完成真实页面验收。
- 设施闭环：同请求幂等重放命中同一记录；`IN_USE → PAUSED → IN_USE → 换设施 → CLEANING_REQUIRED → AVAILABLE` 真实 API 与浏览器流程通过，刷新后暂停状态保持。
- 设施并发：两个终端同时开始同一设施时实测为 `200 + 409 (VERSION_CONFLICT)`，数据库活动会话保持唯一，验收清理后为 0。
- 设施审计：开始、暂停、继续、更换、结束和清洁完成均已产生审计记录。
- 顾客会员 API：顾客建档、卡类创建和开卡同请求重放均为 200；重复手机号为 409、重复卡类编号为 422；开卡后准确产生 3 个独立零余额账户。
- 会员流水约束：真实 PostgreSQL 中更新和删除均被 `55000` 拒绝，测试事务回滚后未残留流水；从空库连续执行三个迁移得到 28 张表。
- 顾客会员浏览器：完成脱敏列表、新建顾客、卡类表单、开卡和账户详情验收；生效日按门店时区显示为 2026-08-18。
