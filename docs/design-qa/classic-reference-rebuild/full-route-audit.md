# 经典版全量路由验收

## 验收范围

- 12个模块首页：收银、顾客、促销、进货、销售、库存、配货、员工、财务、报表、决策、短信。
- 199个清单子页面：逐一访问 `/ui/new/legacy/{moduleKey}/{pageId}`。
- 2个专用页面：设施接待、顾客信息。

## 验收规则

每个子页面必须满足：路由可达、页面标题可见、未出现404或运行时错误；有采集字段或表头的页面还必须呈现对应表单控件、单据明细或数据表格。表单控件数量使用实际渲染的输入框、文本域和选择器复核。

## 验收结果

- 199/199个子页面通过标题与无崩溃检查。
- 首轮结构规则命中193页；剩余6页均为直接表单页，进一步核对后确认实际渲染控件数量不少于最低要求，最终199/199通过。
- 12/12个模块首页通过。
- 设施接待、顾客信息两个专用页面通过。
- 验收期间浏览器控制台没有捕获到错误日志。

## 代表性视觉证据

- `current-document.png`：促销开单，包含单头、单据明细和底部动作。
- `current-grid.png`：员工信息，包含工具栏、分类树和宽表格。
- `current-report.png`：门店经营分析，包含查询条件、工具栏和报表表格。
- `current-form.png`：短信账户，包含直接表单和确定/取消动作。

该验收只证明经典前端页面完整可达并按清单渲染，不把尚未接入的业务后端标记为可用。后端完成状态继续以缺口矩阵和测试品牌端到端证据为准。
