# 经典版页面复刻覆盖说明

## 全量范围

经典版独立运行于 `/ui/new/*`，保留现有新版界面、API、权限和数据。当前参考清单覆盖 12 个模块、199 个子页面：收银10、顾客24、促销8、进货17、销售17、库存19、配货11、员工16、财务19、报表26、决策23、短信9。

199 个页面均有独立路由、页面编号和旧版入口名称；清单中 199 页均记录了可见控件，82 页记录了直接可见字段，24 页记录了直接可见表头。没有采集到字段或表头的页面不得凭空补造旧系统数据，使用模块口径表头和明确的“后端待接入”状态承接。

## 页面形态

- 业务表单页：开卡、储值、积分调整、兑换、短信账户等页面直接呈现各自字段、选项和确定/结算/退出顺序，不再先展示一张通用空表。
- 业务单据页：促销、采购、销售、库存、配送和财务类单据同时呈现单头字段、明细宽表和底部保存/结算动作，不再把单头字段藏进查询弹窗。
- 管理/查询页：复刻顶部工具栏、左侧分类树、宽表格、分页状态栏、查询弹窗、表格密度、打印、导出和退出。
- 报表/决策页：复刻查询条件区、工具栏和结果表格；专项统计接口未接入时展示真实空状态，不用经营总览数字冒充。
- 已接入页面：提供进入现有真实业务的入口；未接入页面只完成前端结构和校验，不提交假单据。

## 当前完成度边界

“页面已复刻”证明路由、旧版名称、工具栏、采集字段、选项、表头和主要可见交互位置存在；不等于对应业务后端已经闭环。后端状态以 `docs/legacy-backend-gap-matrix.md` 为准，必须经过真实测试品牌端到端验证后才能从“部分接入/待接入”改为“已接入”。

顾客首页、顾客信息页以及收银设施与录单流程已经拥有专用经典组件。其余页面现由全量清单驱动的页面形态渲染器承接，后续仍需按模块逐页补专用交互和真实 API。

全量路由、模块首页和代表性视觉验收结果见 [`design-qa/classic-reference-rebuild/full-route-audit.md`](design-qa/classic-reference-rebuild/full-route-audit.md)。
