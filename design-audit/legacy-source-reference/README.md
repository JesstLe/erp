# 老系统客户端源码参考包

本目录保存老板系统在浏览器中实际可见的页面结构，用于经典版 UI 对照重建。

- `index.json`：逐模块图表容器、初始化函数、最新列表字段、右侧分组和按钮行为。
- `*.reference.html`：按浏览器渲染结果整理的客户端结构参考。
- 参考内容仅限浏览器已经收到的 HTML 结构、CSS 类名、按钮文本和前端事件入口，不包含服务器端 PHP 源码。
- 顾客姓名、手机号、业务明细、长编号、账号密码、验证码、Cookie 和表单值均不进入参考包。
- 本目录不是可直接运行的旧系统副本；新经典版使用 React 重建，并继续复用新系统 API、权限和审计规则。

纳入范围：收银、顾客、促销、进货、销售、库存、配货、员工、财务、报表、决策、短信。股权、微信、云商按约定排除。
